# Framework Assets

This folder contains the reusable assets that belong in the shared framework repository.

## Contents

- `workflows/`
- `artifacts/README.md`
- `artifacts/manifests/`
- `artifacts/templates/`
- `starter/`

## Consumption

Copy these assets into a consuming repository's `.ai/` folder using the install script or a similar sync process.

Do not store live consuming-repo task state here.
