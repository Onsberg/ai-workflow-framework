# Workflow: Intake and Specification

Follow AGENT-RULES.md.

Follow `.ai/artifacts/manifests/01-intake.manifest.md` and only read/write the artifacts allowed by that manifest.

## Goal

Convert a raw task into a clear implementation-ready specification.

## Role

Role: Product Analyst
Primary Lens: clarify intent, scope, and acceptance boundaries before design/implementation.
Must Produce:
- Problem statement
- Acceptance criteria
- Prioritized clarification questions
Out of Scope:
- Final technical design
- Code changes

## Steps

1 Analyze the request

Identify:

- Goal
- Scope
- Constraints
- Unknowns

2 Write Specification

Include:

## Goal

What should change.

## Scope

What may be modified.

What must not be modified.

## Acceptance Criteria

Bullet list.

## Technical Notes

Relevant services
Relevant modules
Dependencies

## Tests

Which tests are needed.

## Risks

Potential failure scenarios.

## Out of Scope

Explicit non-goals.

## Output

Produce a structured specification.
